# R1 演示脚本

1. 进入 onboarding，填写成年画像和目标，保存后刷新。
2. 在饮食页添加手动餐食，修改克重，观察今日页营养随数据变化。
3. 在饮食页勾选图片发送同意，上传餐图；检查模型候选，修改食物名和克重后确认保存。
4. 在运动页勾选发送同意，录入“跑步机 4.5 km/h、10% 坡度、中等强度、45 分钟”，确认字段并查看确定性净消耗。
5. 切换 demo，导入固定 14 天案例，查看统计完整率、趋势和训练完成率。
6. 勾选周报模型同意并运行：展示模型实际调用的只读 ToolTrace、证据质量和提案差异；拒绝确认版本不变，再重新分析并批准，刷新后版本增加。
7. 模型未配置、请求失败或未同意时明确展示降级原因，不把测试模拟标成真实成功。
