# 数据来源与计算版本

- Mifflin–St Jeor：`ree-mifflin-st-jeor-v1`，原始研究 PMID 2305711；适用成年健康用户，结果为估算。
- kJ → kcal：`energy-kj-kcal-v1`，`kcal = kJ / 4.184`。
- 运动 MET：`met-compendium-lite-v1`，R0 使用人工核验的活动映射并明确缺失强度不猜测。
- 食物条目：`evofit-curated-cn-v1`，R0 为少量可追踪基础食物；未知营养项保留 null，不转 0。

完整外部数据接入与许可核验属于 R1 前置工作；模型不能替代营养来源。
